Every notebook in one sequence. Wave 1 is Level 1 (my own notes), so the list starts at wave 2. Within a wave, subjects can run in parallel; this list picks one order for them using three rules:

- **Math goes immediately before the first section that uses it.**
- **The subject the next wave depends on goes first.** The other subject trails behind it.
- **A section that uses a result from another subject goes right after that result,** so the link is fresh.

The [diagram on the home page](index.md) shows the same waves.
